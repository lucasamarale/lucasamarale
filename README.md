I am a Partnerships & Channels Manager at **Life Link**, a technology company in Brasília, and a developer who builds systems with AI and ships them. Python pipelines where Claude classifies and writes, a governed knowledge base over MCP, an n8n chatbot, and websites in vanilla code. At work I deploy and demo what I sell, operate in English alongside a vendor SOC, and negotiate international agreements. Computer Science at UniCEUB (2025-2028), with an exchange at BCIT in Vancouver and a year of high school in New Zealand.

The person who writes the pipelines also negotiates the contracts.

## Systems in production

| System | What it does | Stack |
| --- | --- | --- |
| **Court Docket Monitor** *(private, for a law firm)* | Tracks around 200 court cases a day: queries the DataJud API and higher courts, detects new activity by SHA-256 hash, classifies it with Claude and notifies through WhatsApp, email and Google Sheets. Circuit breakers per court, outbox pattern, 150+ pytest cases, CI on GitHub Actions. | `Python` `Claude` `pytest` `GitHub Actions` |
| **[nola AI](https://github.com/lucasamarale/nola-ai-chatbot)** | AI support chatbot for a restaurant-management SaaS, from zero to production in 48 hours. | `n8n` `Groq` `LLaMA` |
| **Lucas Brain** | Obsidian vault with a written constitution: typed frontmatter, controlled vocabulary, write zones. Claude works inside it over MCP, and a pipeline (Quill, Whisper, Python, LaunchAgent) turns recorded meetings into classified, linked notes before I open them. | `Python` `Whisper` `MCP` `Obsidian` |
| **[SUS transfer corrections](https://github.com/lucasamarale/Correcoes-repasses)** | Monetary correction of SUS transfers to hospitals: CSV in, pandas processing, PDF reports and dashboards out. | `Python` `pandas` |
| **Document generator** | Python and Playwright generate branded documents, with a pre-flight verifier that aborts the build on any violation of the visual standard. | `Python` `Playwright` |
| **SharePoint tenant** | Nine corporate sites with defined taxonomy, plus automated writes through the REST API instead of manual upkeep. | `SharePoint` `REST` |
| **[lucasamarale.dev](https://lucasamarale.dev)** | This portfolio: one vanilla HTML file with a scroll-locked 3D intro, canvas engines and a bilingual build. No frameworks, no build step, deployed on Netlify. | `HTML` `CSS` `JS` |
